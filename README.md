# Qasid VPN

Phone-buildable Android VPN starter project.

IMPORTANT:
This project demonstrates Android's VpnService and creates a local VPN/TUN interface.
It is NOT yet a production VPN and does not provide encrypted Internet access by itself.

Before Play Store release:
- Add a real VPN tunnel/backend (for example WireGuard).
- Add server configuration and key management.
- Add privacy policy and accurate Data Safety declarations.
- Test DNS, IPv4/IPv6, reconnects, battery use, and kill-switch behavior.
- Complete Google Play's VPN-related policy requirements.
